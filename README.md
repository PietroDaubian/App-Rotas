# Rotas de Clientes

App web para celular: tabelas tipo Excel (Cliente, Local, Endereço, CEP) com atalho para Google Maps e Apple Maps.

## Arquivos (todos na mesma pasta, como o Greenback)
- `index.html` — o app (interface, estilos e código)
- `manifest.webmanifest`, `sw.js` — instalação no celular e modo offline
- `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — ícones

## Publicar no GitHub Pages
Envie todos os arquivos para a raiz do repositório (público), depois Settings > Pages > Deploy from a branch > `main` / `(root)`.

## Diagnóstico
Abra o endereço do app com `#diagnostico` no final para ver o que falta para instalar.
